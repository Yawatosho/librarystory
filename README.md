# YOUR LIBRARY STORY

図書館にまつわる記憶をカードから選び、いくつかの問いをたどったあと、集まったカードを見返すブラウザ作品の初期プロトタイプです。診断や性格分類ではなく、ユーザーが選んだ記憶そのものを主役にしています。

## 実装した体験

- 静かなタイトル画面から開始
- 50枚を一度に見せず、意味タグの偏りを抑えた8枚を提示
- 1枚の記憶につき、紐づく質問から2〜3問を選択（時期の質問は4回中おおむね3回）
- 4回の記憶選択後、代表的な3〜4枚をカードとして表示
- カードと回答のタグを内部で重みづけし、次の8枚と代表カードの選択に利用
- `relatedCardIds` と共有タグによる近い記憶、未探索タグ、少し遠い記憶をおおむね 4:3:1 で混在
- 結果後も未提示カードを中心に、別の記憶を1枚ずつ追加可能
- `localStorage` に進行を保存し、再読み込み後は「つづきから」で復帰
- JSON不在・破損時のエラー画面、質問がないカードのスキップ処理
- 375px前後の縦画面を基準にしたレスポンシブUIと、動きを減らすOS設定への対応

内部のタグ得点は画面に表示せず、「結果」や「分析」ではなく、集まった記憶を見る構成にしています。

## ファイル構成

```text
.
├── index.html              # 各画面のHTMLと基本メタ情報
├── style.css               # 紙・写真・図書館カードを意識した見た目と動き
├── app.js                  # 設定、進行状態、保存・復帰、画面描画
├── selection.js            # カード推薦、質問抽出、意味ネットワーク集計
├── result.js               # 代表カードと、カードに添える回答情報の選択
└── data/
    └── your-library-story-memory-data-v01.json
```

## 起動方法

ES Modules と `fetch()` を使うため、ファイルを直接開かずHTTPサーバー経由で確認します。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開いてください。ビルド処理や外部ライブラリは不要です。

## GitHub Pages

すべて相対パスで参照しているため、そのままリポジトリのルートをGitHub Pagesの公開元にできます。GitHubのリポジトリ設定で **Settings → Pages → Deploy from a branch** を選び、対象ブランチの `/ (root)` を指定します。

## 調整しやすいポイント

`app.js` 冒頭の `CONFIG` で、次の値を変更できます。

- `displayCardCount`: 一度に見せるカード数
- `playRounds`: 最初の結果までに選ぶ記憶数
- `questionMin` / `questionMax`: 1枚あたりの質問数
- `resultCardCount`: 結果に残す代表カード数
- `recommendation`: 近い／未探索／意外なカードの比率

JSONの `selectionRules` に同じ設定がある場合、カード数と推薦比率はJSON側を優先します。カードや質問は、JSONの `cards` / `questions` に追加し、カードの `questionIds` と `relatedCardIds` を結ぶだけで増やせます。

回答ラベルから加える意味タグは `selection.js` の `ANSWER_TAG_RULES` で調整できます。代表カードの選択は、意味ネットワークの中心性、他と少し異なる記憶、回答された具体情報の多さを組み合わせています。

## v0.2で調整したこと

- 画面の案内と結果文を、抽象的・詩的な表現から日常的な言葉へ変更
- 最終結果の都合が見える `q038` / `q039` をデータ上で無効化し、保存済みの進行からも除外
- `q001`（時期）を毎回は出さず、4回中おおむね3回に調整
- 代表カードの判定から自己評価を外し、回答の具体性を評価材料に追加
- 記憶カードの角度、上下位置、横位置、幅、最小高、内側余白をカードID由来の固定値で変化
- hover・フォーカス・選択時はカードが少し持ち上がり、傾きが小さくなるように調整
- 結果カードもカードID由来の角度と位置で、軽く重なる配置に変更

## v0.3で調整したこと

- 結果画面からルールベースの短文と時間軸を削除
- 結果画面の見出しを `YOUR LIBRARY STORY` のみに整理
- 記憶カードと結果カードから `MEMORY 01` などの連番を削除
- 記憶選択の `1 / 4` などの進捗表示を削除（質問画面の質問数表示は維持）
- カードID由来の配置を保ちながら、幅・横位置・上下位置・カード間の余白差を拡大
- 結果後の導線を「ほかの記憶も見る」に変更
- 代表カードにはタイトルと、回答から得られた具体的な情報を最大2件だけ表示

## プロトタイプとして今後検討できること

- 実際のプレイ観察に基づく質問数と文章テンポの調整
- タグや関連カードの編集を支援する簡易データ検証ツール
- 結果の印刷・画像保存（共有機能は利用者の意向を見て追加）
- 端末をまたぐ保存が必要になった場合のみ、バックエンド保存を検討
